# Theme

## Target files

- `.tmux.conf`
- `.bash.d/prompt.bash`
- `.vimrc`
- `private.d/config.d/peco/config.json`

## Usage

```bash
./theme/sync teal && tmux source-file ~/.tmux.conf
```

## Allowed options

| Theme | Accent | Selected |
| --- | --- | --- |
| `teal` | `#1bafb5` | `#79bfc0` |
| `violet` | `#9180d8` | `#b1a5e5` |
| `orange` | `#d98d50` | `#e9b888` |
| `blue` | `#579cda` | `#96bfe9` |
