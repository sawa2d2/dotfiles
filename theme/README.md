# Theme

## Target files

- `.tmux.conf`
- `.bash.d/prompt.bash`
- `.vimrc`
- `theme/generated/fzf.sh`

## Usage

```bash
./theme/sync teal
```

## Allowed options

| Theme    | Accent    | Selected  |
| -------- | --------- | --------- |
| `teal`   | `#1bafb5` | `#79bfc0` |
| `violet` | `#9180d8` | `#b1a5e5` |
